# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly by emailing security@authdog.com. Do not open a public issue.

## Whitehat Program

We run a whitehat program for security researchers who responsibly disclose vulnerabilities. For details on scope, eligibility, and rewards, see https://www.authdog.com/whitehat.
